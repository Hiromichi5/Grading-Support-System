# 📂 Proposal_system - README

## 🧾 概要

本ディレクトリは、テスト採点業務の効率化を目的とした **提案システム** を構成するコードや学習済みモデルを格納しています。加速度センサを搭載したペンの動きから「○」「×」などの採点動作をリアルタイムで検出し、採点者の集中力低下を防ぐ支援を行います。

本システムでは、以下の支援を提供します：

- **リアルタイム動作判定（加速度センサ）**
- **採点効率の数値化と記録**
- **作業効率の視覚的・聴覚的フィードバック**

---

## 📁 ディレクトリ構成
    Proposal_system/ 
    ├── pycache/ # Pythonのキャッシュフォルダ（自動生成） 
    ├── camera.py # 採点数を画像から取得するプログラム（正解データ作成用） 
    ├── proposal_system.py # 提案システムのメイン実行スクリプト 
    ├── settings.py # 動作判定や警告条件などの設定ファイル 
    ├── sound/ # 警告音や通知音を格納 
    ├── _others/ # 補助スクリプトや一時ファイル 
    └── Model/ # 学習済みモデル（分類器・オートエンコーダ・CNN等）

## 📄 各ファイル・フォルダの詳細

### `camera.py`

- 📷 採点用紙を上から撮影し、**赤ペンで書かれた記号の数**をカウントします。
- 提案システムの検出精度を評価するための **正解ラベル（ground truth）** 作成に使用します。

### `proposal_system.py`

- 🧠 本システムのメイン処理。
  - 加速度センサからリアルタイムにデータを取得。
  - 採点動作（○、×など）を自動判定。
  - 一定時間ごとに **作業効率スコア** を算出。
  - 効率低下時に以下の通知を実施：
    - 📊 視覚的通知（スコア表示）
    - 🔊 聴覚的通知（警告音再生）

### `settings.py`

- ⚙️ 提案システムの各種パラメータを管理。
  - 加速度しきい値、判定ウィンドウサイズ、警告の条件など。
  - センサポート設定（USB, BLE など）

### `sound/`

- 🔉 警告音や通知音を格納したフォルダ。
- 使用する音声ファイルは `.wav` や `.mp3`。
- デフォルト音声は差し替え可能（`settings.py` 内でパス指定）。

### `_others/`

- 🗂️ 実験中に使用した補助スクリプトや一時保存ファイル。
- 公開・配布時には整理・削除してください。

### `Model/`

- 🤖 学習済みの分類器・オートエンコーダモデルを格納。
- 提案システム内で自動ロードされ、入力センサデータの分類に使用されます。

## 🚀 実行手順

### 1. 🛠 仮想環境のセットアップ

1. 仮想環境を作成します（初回のみ）：
    ```bash
    python -m venv myenv
    ```

2. 仮想環境を有効にします：

    - Mac/Linux：
      ```bash
      source myenv/bin/activate
      ```

    - Windows：
      ```bash
      myenv\Scripts\activate
      ```

3. 依存ライブラリをインストールします：
    ```bash
    pip install -r requirements.txt
    ```

> ※ Python 3.8 〜 3.10 あたりを推奨します。

### 2. 🛠 実行
    python3 proposal_system.py 0 (settings.pyで設定したMACアドレスで0番目のセンサを利用する場合)
